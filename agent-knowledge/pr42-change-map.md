## 关键决策记录（本次沉淀的"为什么"）

1. **恢复即休眠**：恢复 50 标签会话若全部立即加载会爆 CPU/内存；改为等导航提交后 discard，URL 保住、页面不完整渲染。
2. **Chrome 组指纹 = window+title+color**：避免把用户自建组误判为镜像；持久化从扁平改为 per-window，重启后按窗口重匹配。
3. **移除整窗重排**：卡片顺序跟随 Chrome 组条顺序，窗口布局交还用户（不强行按面板顺序重排标签条）。
4. **stale-retry 统一**：渲染与点击竞态不拖垮整批操作，真实 API 错误仍透出。
5. **同步开关与事件订阅解耦**：即使 push 关闭，dashboard 仍需实时识别用户组卡片（live 识别）。
6. **popup 动画契约**：入场动画只在视图切换时播，后台刷新绝不重播——修复面板空白回归的根因。
